# 사용 방법

## 로그인 전

로그인 전에는 서비스 소개와 Google 로그인 버튼, 개인정보처리방침, 이용약관만 표시됩니다. 게시글 제목, 작성자, 댓글, 개인 작업 티켓은 노출되지 않습니다.

## Google 로그인

`Google 계정으로 로그인`을 누르고 계정을 선택합니다. 운영자가 가입 범위를 제한한 경우 허용 이메일이나 Workspace 도메인에 포함된 계정만 들어갈 수 있습니다.

Google 이름과 프로필 사진은 게시판에 사용하지 않습니다. 첫 로그인 시 임시 닉네임이 생성되며 `내 계정`에서 바꿀 수 있습니다.

## 탑바

인증 후 모든 화면 위에는 고정 탑바가 있습니다.

- 왼쪽: 현재 화면 제목 또는 이전 화면 버튼
- 오른쪽: 현재 문맥의 가장 중요한 동작
- 가장 오른쪽: 전체 메뉴 아이콘 하나

예를 들어 자유게시판에서는 `글쓰기`, 문의에서는 `문의 작성`, 내 메모에서는 `URL 설정`, 내 작업에서는 `티켓 추가`, 개인 이미지 저장에서는 `이미지 선택`, 본인 게시글 상세에서는 `수정`이 문맥 동작으로 표시됩니다.

메뉴 아이콘을 누르면 다음 항목이 열립니다.

```text
자유게시판
문의
내 메모
내 작업
개인 이미지 저장
내 계정
로그아웃
```

## 자유게시판

로그인한 모든 회원이 글과 댓글을 읽고 작성할 수 있습니다.

- 작성자는 본인 글과 댓글을 수정·삭제할 수 있습니다.
- 관리자는 공용 게시판의 모든 글과 댓글을 관리할 수 있습니다.
- 내용은 일반 텍스트로 저장됩니다.
- 이미지, HTML, 첨부파일은 지원하지 않습니다.

## 문의

현재 버전의 문의 게시판은 자유게시판과 마찬가지로 로그인 회원 전체에게 공개됩니다. 비공개 고객문의가 아닙니다. 민감한 개인정보, 계정 비밀값, 결제정보를 적지 마세요.

## 내 메모

`메모`와 `값`을 저장하는 본인 전용 목록입니다. 별도의 상세 페이지 없이 목록에 값이 바로 표시됩니다.

- 숫자 값과 문자 값에 서로 다른 URL 앞부분·뒷부분을 설정할 수 있습니다.
- 설정에서 이름, 앞 URL, 뒤 URL로 구성된 사용자 패턴을 최대 50개까지 추가할 수 있습니다.
- 메모를 저장할 때 `자동` 또는 사용자 패턴 하나를 선택합니다.
- `자동`은 기존과 동일하게 값이 숫자인지 판별하고 숫자·문자 기본 패턴 중 하나를 적용합니다.
- 사용자 패턴을 선택하면 값의 숫자 여부와 관계없이 선택한 패턴을 적용합니다.
- 값을 누르면 `앞 URL + 인코딩된 값 + 뒤 URL`로 조합한 주소로 이동합니다.
- 숫자는 부호와 소수를 포함한 숫자 문자열로 판별하며, 그 외 값은 문자 규칙을 사용합니다.
- 해당 유형의 URL 설정이 비어 있으면 값은 표시되지만 링크는 비활성화됩니다.
- 사용자 패턴을 삭제하면 해당 패턴을 쓰던 메모는 `자동` 판별로 전환됩니다.
- 저장과 삭제를 포함한 모든 쿼리는 현재 로그인 사용자의 ID로 제한됩니다.

## 내 작업

본인만 사용하는 간단한 포스트잇 보드입니다.

```text
할 일 → 진행 중 → 완료
```

티켓에는 다음 항목만 있습니다.

- 제목: 최대 120자
- 메모: 최대 4,000자
- 상태
- 같은 열 안의 순서

카드의 끌기 손잡이로 같은 열에서 순서를 바꾸거나 다른 열로 이동할 수 있습니다. 키보드, 드래그 미지원 브라우저 또는 JavaScript 비활성 환경에서는 카드 아래의 좌우 이동 버튼과 `열기` 링크를 사용할 수 있습니다.

개인 티켓 API는 URL의 사용자 ID를 받지 않으며 현재 로그인 세션의 사용자 ID로만 조회·수정합니다. 다른 회원의 티켓 ID를 알아도 접근할 수 없습니다.

## 개인 이미지 저장

본인만 이미지 목록을 볼 수 있는 개인 저장 화면입니다.

- JPEG, PNG, WebP, GIF, AVIF 형식만 업로드할 수 있습니다.
- 파일은 최대 5 MiB이며, 초과 여부를 브라우저에서 먼저 확인해 네트워크 요청 전에 거절합니다.
- Worker는 로그인·소유권을 확인하고 짧게 유효한 업로드 URL만 발급합니다. 이미지 본문은 브라우저에서 R2로 직접 전송됩니다.
- 이미지는 R2 Custom Domain의 공개 캐시 URL로 표시됩니다.
- 이미지 아래의 `[복사]`를 누르면 캐시 URL이 클립보드에 복사되고, 오른쪽 아이콘에 복사 이력이 남습니다.
- 캐시 URL은 공개 주소이므로 복사해 공유한 뒤에는 로그인하지 않은 사람도 그 주소로 이미지를 볼 수 있습니다.

R2 설정이나 Worker Secret이 아직 없다면 업로드 시 설정 오류 toast만 표시되며 다른 화면은 계속 사용할 수 있습니다.

## 내 계정

게시글과 댓글에 표시할 닉네임을 변경할 수 있습니다.

허용 문자:

```text
한글과 기타 문자, 숫자, 공백, 밑줄, 하이픈
```

길이는 2~24자입니다. Google 이메일은 로그인 식별과 운영 허용 확인에만 사용됩니다.

## 로그아웃

오른쪽 메뉴 아래의 `로그아웃`을 누르면 서버의 세션 레코드와 브라우저 쿠키가 함께 삭제됩니다.

## 모바일 사용

탑바와 메뉴는 모바일에서도 같은 구조를 유지합니다. 작업 보드의 세 열은 화면 폭이 좁으면 가로로 스크롤되고, 개인 이미지는 한 열 카드로 표시됩니다.
